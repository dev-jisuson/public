Unit Test Execution

실행

cd backend  && .venv/bin/python -m pytest          # backend 단위 + API 테스트
cd frontend && npm test                            # Vitest (jsdom)

결과 확인

  • 보고서 파일은 만들지 않고 콘솔로 확인합니다.
  • 커버리지는 측정하지 않았습니다 (도구 미설정). 대신 요구사항·스토리 인수 조건 기준으로 테스트를 작성했고, 상태 버튼 규칙은 변이(규칙을 일부러 깨뜨림)로 테스트가 실패하는지 확인했습니다.

실패 시

  1. 실패한 테스트 이름과 출력 확인
  2. -k 이름 으로 단독 실행해서 순서 의존인지 확인 (테스트는 서로 독립이며 backend는 3회 연속 실행으로 확인)
  3. 수정 후 전체 재실행
