이 단계에서 발견해 고친 것

  1. 서버가 열린 SSE 연결이 있으면 종료되지 않음 (backend). uvicorn이 연결 종료를 기다려서 lifespan 정리 코드가 실행되지 못함. 이전에 "정상 종료"라고 본 것은 curl 스트림이 먼저 타임아웃된 경우였음. → --timeout-graceful-shutdown을 Dockerfile과 실행 명령에 추가. 종료 약 2.2초, 컨테이너 정지 4초.
  2. 관리자 주문 상세의 상태 배지가 세로로 늘어남 (frontend CSS)
  3. 메뉴 카드가 3개인 카테고리에서 오른쪽이 비는 레이아웃 (frontend CSS)
  4. 호스트 3000번 포트 충돌 → FRONTEND_PORT/BACKEND_PORT로 변경 가능하게 함
