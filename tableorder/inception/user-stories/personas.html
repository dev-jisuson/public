Personas

P1. 테이블 고객 — "김손님"

  • 누구인가: 매장에 방문해 테이블에 앉은 손님. 일행과 함께 식사하며, 테이블에 놓인 태블릿으로 주문합니다.
  • 상황:
    • 태블릿은 이미 관리자가 설정해 두었기 때문에 로그인을 직접 하지 않습니다.
    • 식사 중에 여러 번 추가 주문을 할 수 있습니다.
  • 목표:
    • 직원을 부르지 않고 바로 주문하기
    • 내가 시킨 메뉴가 언제 나오는지 알기
    • 지금까지 얼마나 주문했는지 확인하기
  • 불편 요소:
    • 메뉴를 찾기 어렵거나 버튼이 작아서 잘못 누르는 경우
    • 주문이 제대로 들어갔는지 확신하지 못하는 경우
    • 음식이 언제 나올지 몰라 계속 기다리는 경우
  • 기술 숙련도: 낮음~보통. 화면 구성이 단순하고 터치하기 쉬워야 합니다.
  • 사용 화면: 고객용 웹UI (태블릿 브라우저)

P2. 매장 운영자 — "박사장"

  • 누구인가: 매장을 운영하며 홀/주방 상황을 관리하는 사람. 시스템상 관리자 계정 1종을 사용합니다. 직원 권한 구분은 범위 밖입니다.
  • 상황:
    • 영업 시간 동안 관리자 화면을 계속 띄워 두고 들어오는 주문을 확인합니다.
    • 메뉴 준비 시작, 서빙 직전 완료 처리, 손님이 나가면 이용 완료 처리를 합니다.
  • 목표:
    • 신규 주문을 놓치지 않기
    • 테이블별 주문 현황과 총액을 한눈에 보기
    • 손님에게 정확한 예상 시간 알려주기
    • 테이블 회전 빠르게 처리하기
  • 불편 요소:
    • 주문이 몰릴 때 어떤 테이블의 어떤 메뉴가 대기 중인지 헷갈리는 경우
    • 잘못 들어간 주문을 정정하기 어려운 경우
    • 이전 손님의 주문이 다음 손님에게 섞이는 경우
  • 기술 숙련도: 보통
  • 사용 화면: 관리자용 웹UI (PC 또는 태블릿 브라우저). 태블릿 초기 설정 시에는 고객용 화면의 설정 메뉴도 사용
