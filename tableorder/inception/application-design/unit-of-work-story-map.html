Unit of Work — Story Map

표기

  • ● 주 담당: 인수 조건의 핵심 동작을 구현합니다.
  • ○ 보조: 화면 표시 또는 API 제공만 맡습니다.
스토리 제목 backend frontend
US-C01 태블릿 초기 설정 ● 로그인 API, 잠금 ● 설정 화면, localStorage 저장
US-C02 자동 로그인 ○ 토큰 검증 ● 저장 정보로 진입
US-C03 토큰 만료 시 자동 재로그인 ○ 401 응답 ● 재로그인 후 재시도
US-C04 카테고리별 메뉴 카드 ● 메뉴 API, 정적 이미지 ● 카드 UI, 플레이스홀더
US-C05 카테고리 빠른 이동 ●
US-C06 장바구니 담기 ●
US-C07 수량 조절/삭제 ●
US-C08 장바구니 비우기 ●
US-C09 새로고침해도 유지 ●
US-C10 주문 확인/확정 ● 주문 생성, 세션 시작 ● 확인 화면
US-C11 주문 성공 안내 ○ 주문 번호 ● 5초 후 이동
US-C12 주문 실패 처리 ○ 에러 응답 ● 장바구니 유지
US-C13 현재 세션 주문 내역 ● 세션 필터, 페이지네이션 ● 목록, 무한 스크롤
US-C14 항목 상태/남은 시간 ● 주문 상태 결정, 예상 시각 ● 카운트다운, "곧 나옵니다"
US-C15 실시간 갱신 ● 테이블 채널 이벤트 ● SSE 반영
US-C16 완료 알림 배너 ○ 이벤트 ● 토스트
US-A01 관리자 로그인 ● JWT, bcrypt ● 로그인 화면
US-A02 로그인 유지/자동 로그아웃 ● 16시간 만료 ● 만료 타이머
US-A03 로그인 시도 제한 ● 5회/15분 잠금 ○ 안내 메시지
US-A04 그리드 대시보드 ● 대시보드 API ● 그리드 UI
US-A05 신규 주문 실시간 강조 ● 매장 채널 이벤트 ● 강조/해제
US-A06 주문 상세 ● 상세 API ● 모달
US-A07 테이블 필터 ●
US-A08 준비 시작(시간 필수) ● 전이/검증 ● 입력 다이얼로그
US-A09 전체 준비 시작 ● ●
US-A10 예상 시간 수정 ● ●
US-A11 완료 처리 ● 전이 규칙 ● 버튼 노출 규칙
US-A12 테이블 등록/비밀번호 ● ● 관리 화면
US-A13 주문 삭제 ● 삭제, 총액 재계산 ● 확인 팝업
US-A14 이용 완료 ● 보관 표시, 세션 종료 (트랜잭션) ● 확인 팝업, 카드 리셋
US-A15 과거 내역 ● 보관 주문 조회, 날짜 필터 ● 모달
US-I01 주문 → 대시보드 ● 이벤트 발행 ● 수신/반영
US-I02 상태 변경 → 고객 화면 ● 채널 분리 ● 수신/반영
US-I03 이용 완료 → 태블릿 초기화 ● 이벤트, 상태 API ● 초기화, 재접속 동기화
US-I04 주문 삭제 → 태블릿 ● ●
US-I05 재연결 동기화 ● 상태 조회 API, ping ● 재연결, resync
US-I06 매장/테이블 데이터 분리 ● 범위 강제

배정 점검

  • 37개 스토리 모두 하나 이상의 단위에 배정되어 있습니다.
  • backend 단독 스토리는 1개입니다: US-I06
  • frontend 단독 스토리는 6개입니다: US-C05, C06, C07, C08, C09, US-A07
  • 나머지 30개는 두 단위가 함께 구현합니다.
